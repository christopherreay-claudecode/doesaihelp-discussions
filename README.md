# doesaihelp-discussions

Public comment threads for [doesaihelp.org](https://doesaihelp.netlify.app).

Every point on the site (a headline, a support, a gap, a part of a testable headline) has its own discussion here, shown in place on the page through [giscus](https://giscus.app). Comment on the site, or here directly: both are the same thread.

Each discussion's title is the stable id of the point it belongs to, for example `thePerson/03-whoClosesTheGap#support-2`. Please don't rename discussions, or the thread loses its place on the page.

Good comments can become proposals: a maintainer can turn a discussion into an issue on the project.
